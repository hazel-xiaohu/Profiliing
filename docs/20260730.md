# 2026-07-30 工作日志

## 1. 当前目标

将当前分块实验拆分为两个问题：

1. 先为每个矩阵选择一个较优的统一规则 NB；
2. 再判断混合尺寸 Greedy/DP 是否能稳定优于最佳统一 NB。

这样可以区分“块大小选得更合理”的收益与“组合优化”的真实增量收益。

9 个完整矩阵、单次运行的 pipeline 几何平均结果：

| 配置 | 相对 Main native 收益 | 获胜数 |
|---|---:|---:|
| Main fixed `P=4096` | 11.69% | 6/9 |
| Partition no-merge | 15.71% | 7/9 |

逐层增量：

- Main native → fixed P：11.69%；
- fixed P → no-merge：4.55%，其中可能包含实现路径与单次波动，不能视为组合优化收益；
- no-merge → Greedy：2.89%，仅 4/9 获胜；
- Greedy → DP：1.31%，5/9 获胜。

DP 在当前可加预测模型下全局最优，但 Greedy 的预测 regret 只有 0～0.37%。
因此搜索器已经接近模型最优，当前主要限制是代价函数与 GPU 实际执行时间之间的偏差。

决策开销中位数：no-merge 0.742 ms、Greedy 2.814 ms、DP 2.853 ms；
Greedy/DP 约占 pipeline 的 0.021%，已不是主要瓶颈。

## 3. 统一 NB 寻优实现

在 `Partition/src/pangulu_partition_greedy_v1.h` 新增：

```bash
PANGULU_PARTITION_ALGORITHM=uniform_nb
```

当前规则：

- 基本粒度 `P=4096`；
- 默认候选 `4096,8192,12288,16384`；
- 对每个候选统一 NB，按 symbolic cache 生成各层 GETRF、GESSM、TSTRF、dense-SSSSM 的 count、operations 和 bytes；
- 使用现有已核验的 Roofline 代价逐层累加；
- 选择预测总时间最小的统一 NB；
- 相对 `NB=4096` 的预测收益不足 5% 时回退到 4096；
- 保持 `block_common->ptr[]` 接口不变。

现有 kernel profiling 最大训练尺寸为 16384，因此默认拒绝选择 20480。后续补充大尺寸训练数据后，可通过：

```bash
PANGULU_PARTITION_UNIFORM_MAX_NB=20480
```

显式提高候选上限。
