## 2. 当前 symbolic 分块决策

当前候选步长：

```text
SLAB_SIZE = 2048
MAX_SLAB_PER_BLOCK = 5
```

每个候选比较：

```text
T_no_cut = GETRF(whole) + no-cut penalties

T_cut = GETRF1 + GESSM + TSTRF + SSSSM + GETRF2
      + launch + preprocess + symbolic + small-task penalties
```

今日明确修正：GESSM 与 TSTRF 按串行时间相加，不再取 `max()`，也不再使用
overlap makespan：

```c
c.kernel_ms = t1 + tg + tt + ts + t2;
c.makespan_ms = c.kernel_ms;
```

决策仍包含：

- 绝对收益阈值；
- 相对收益阈值；
- OOD 检查；
- 小任务惩罚；
- launch/preprocess/symbolic 额外开销；
- `MAX_SLAB_PER_BLOCK` 硬上限。

## 3. Symbolic view 扫描优化

### 3.1 单候选合并扫描

原始候选分别构造 whole、A11、A22、Ug、Lt，并对 A/L/U 重复扫描。

目前一次 suffix CSC 遍历同时构造 11 个 view：

```text
aw, lw, uw
a1, l1, u1
a2, l2, u2
ug, lt
```

扫描次数从最初约 11 遍降为 1 遍。逐字段等价性测试覆盖：

- NNZ；
- row/column NNZ；
- CSR/CSC gap mean、CV、consecutive fraction。

结果：

```text
candidate views equivalence: PASS
```

### 3.2 Reusable workspace

11 个 view 的 `rn/cn/first/last` 改为可增长的持久 workspace：

- 候选间复用内存；
- 避免反复 `malloc/calloc/free`；
- symbolic 决策结束后统一释放；
- view 增加内存所有权标记，避免释放 workspace 缓冲区。

### 3.3 精确 rolling suffix cache

利用严格等价关系：

```text
candidate i 的 whole GETRF
=
candidate i-1 的 GETRF2
```

缓存上一候选的 GETRF2 特征，下一候选命中时直接作为 whole GETRF 特征。
缓存键检查：

- global matrix size；
- expected origin；
- L/U pointer identity。

不连续调用或结构指针改变时自动回退完整构造。

## 5. 轻量 online-safe 模型

### 5.1 删除的昂贵特征

根据 v3 消融结果，删除在线计算代价高、对 MAPE 改善有限的特征：

```text

block_csc_index_gap_cv
block_csc_consecutive_fraction
derived_csr_index_gap_mean
derived_csr_index_gap_cv
derived_csr_consecutive_fraction
```

同时删除在线 SSSSM histogram：


## 7. 在线运行与训练集边界

明确不实现边求解边自动训练。

在线运行只做：

```text
symbolic L/U
→ 临时提取候选特征
→ 固定轻量模型推理
→ T_cut / T_no_cut 比较
→ 输出 ptr[]
```

不会自动：

- 将新矩阵样本加入训练 CSV；
- 生成真实 kernel runtime 标签；
- 修改训练集；
- 重新训练模型；
- 覆盖生成的 C/C++ 模型头文件。

若设置 `PANGULU_PARTITION_CANDIDATE_LOG`，也只是显式候选日志；没有
`actual_no_cut_ms/actual_cut_ms` 时不能作为监督训练标签。
