| NB | Oracle wins | Median regret | Geomean regret | P90 regret | Max regret |
|---:|---:|---:|---:|---:|---:|

预先采用的选择规则为：在最佳 geomean regret 的 1 个百分点以内、且 P90 regret 不超过 10% 的候选中选择最小粒度。该规则选择：


- leave-one-matrix-out：16/16 轮选择 2048；
- 10,000 次矩阵级 bootstrap：2048 选择率 75.31%，4096 为主要替代项 24.53%。

这里的 LOO 是参数选择稳定性分析，不是模型泛化交叉验证。

## 4. MAX_NUM 右边界探测

由于 `G3_circuit`、`ecology1`、`inline_1` 在当前右边界 NB=16384 处胜出，只对这 3 个矩阵补测：

```text

```

```text
24576 = 12P
32768 = 16P
```

6 个新增组合全部成功，仍采用 0 warmup、1 次正式测量。

| 矩阵 | NB=16384 | NB=24576 | NB=32768 | 扩展后最优 |
|---|---:|---:|---:|---:|
| G3_circuit | **5.728 s** | 6.830 s | 5.901 s | 16384 |
| ecology1 | 2.842 s | **2.437 s** | 2.664 s | 24576 |
| inline_1 | **5.591 s** | 6.261 s | 5.694 s | 16384 |

相对 16384：

- G3_circuit：24576 慢 19.25%，32768 慢 3.04%；
- ecology1：24576 快 14.24%，32768 快 6.27%，但 32768 不如 24576；
- inline_1：24576 慢 11.97%，32768 慢 1.84%。

对 10 个完整矩阵，候选上界从 16384 扩展到 24576 后，规则 oracle 几何平均时间从 11.6447 秒降至 11.4671 秒，改善约 1.52%。继续加入 32768 后没有任何新增 oracle 改善。

因此，下一轮 profiling 的暂定上界选择为：

```text
MAX_NUM = 12
max block size = 24576
```

这是一项 profiling-domain calibration：它说明覆盖到 `12P` 有实际价值，而扩大到 `16P` 暂未带来收益；它不证明 12 是连续尺寸空间中的理论全局最优值。

## 8. 今日形成的论文方法叙述

建议将参数选择流程描述为：

1. 使用与正式测试集隔离的 calibration set 确定最小组成粒度 `P`；
2. 使用较大矩阵的规则 NB 实测确定值得 profiling 的尺寸上限；
3. 在当前 GPU 平台上得到 `P=2048, MAX_NUM=12`；
4. 正式 profiling 覆盖 `P, 2P, ..., MAX_NUM*P`；
5. 训练 kernel 性能模型；
6. 以规则 `NB=P` 或模型选择的规则 NB 作为安全基线；
7. 只有预测收益显著时采用 mixed Greedy 合并。

`P` 的准确定位是最小组成粒度，而不是 kernel 吞吐饱和点；`MAX_NUM` 是 profiling 和在线搜索域上限，而不是最终所有块的固定大小。

换 GPU 平台后，不直接沿用数值 2048/12，而是保持相同校准流程，在新平台重新确定参数并重新 profiling。

## 9. 仍需谨慎的地方

1. 大矩阵固定 NB 和 Greedy 均为单次测量，不能用来声称小于约 5% 的差异具有统计显著性。
2. 当前“规则 oracle”是已测候选集合中的 oracle，不是连续 NB 空间的理论 oracle。
3. 只有 G3_circuit、ecology1、inline_1 测过 24576；其他 7 个完整矩阵的规则 NB 只覆盖到 16384。
4. 当前 kernel 模型尚未针对 `P,2P,...,12P` 完整重新 profiling。超过旧训练上界 16384 的预测属于未正式校准区域。
5. Greedy 在 ASIC_680k 上数值时间退化 24.89%，在 SiO2 上退化 9.32%，表明必须实现规则基线回退和最小收益阈值。
6. Greedy 超过已测规则 oracle 是合理的，因为 mixed-size partition 不属于 uniform-NB 候选空间；但正式论文仍需通过重复测量确认。
7. calibration 矩阵与最终外部测试矩阵必须继续保持不重叠。

## 10. 下一步建议

按有限时间收敛，建议顺序如下：

1. 冻结 `P=2048, MAX_NUM=12` 作为 RTX PRO 6000 的 profiling-domain calibration 结果；
2. 正式 profiling 覆盖：

   ```text
   2048, 4096, 6144, 8192, 10240, 12288,
   14336, 16384, 18432, 20480, 22528, 24576
   ```

3. GESSM/TSTRF 同时按 symbolic 实际分布覆盖矩形尺寸和 aspect ratio，而不是只采方块；
4. 重新 feature replay、严格连接和训练正式 kernel 模型；
5. 增加安全决策：预测收益小于阈值或超出训练分布时回退规则 NB；
6. 对 ASIC_680k、SiO2 以及 Greedy 优势最大的矩阵各重复至少 3 次，确认正负收益；
7. 最终外部测试集不得包含今天已经用于 calibration 的矩阵；
8. 论文主结论同时报告 numerical 和 end-to-end pipeline，且单独报告 decision overhead。

今天最重要的阶段性结论是：规则 NB 选择确实很强，但在当前 10 个较大矩阵上，`P=2048, MAX_NUM=12` 的 mixed Greedy 仍显示出超过已测规则 oracle 的初步端到端收益；后续工作的重点应从“证明规则 NB 不够好”转为“通过安全回退，只在混合分块确实有收益时采用 Greedy”。
